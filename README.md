# Распознавание и синонимическое обезличивание персональных данных (Вариант 24)

Курсовая работа по дисциплине «Цифровые технологии защиты информации».

Программный комплекс автоматически выявляет персональные данные (ПДн) в неструктурированных русскоязычных текстах и выполняет их синонимическое обезличивание с сохранением морфологических характеристик (род, число, падеж), структуры, косвенных признаков, контрольных разрядов и свойства идемпотентности.

---

## 1. Поддерживаемые атрибуты ПДн (Вариант 24)

| Атрибут | Тег | Метод распознавания | Что сохраняется при синонимическом обезличивании |
|---|---|---|---|
| Фамилия | `SURNAME` | Дообученная нейросеть `RuBERT` | Род, число, падеж, регистр, дефисная структура, идемпотентность |
| Имя | `NAME` | Дообученная нейросеть `RuBERT` | Род (включая контекстное разрешение имён `Саша`/`Женя`/`Валя`), число, падеж, регистр |
| ИНН | `INN` | Регулярное выражение + проверка КР ФНС (10 и 12 цифр) | Первые 4 цифры (код ИФНС), длина, разделители, валидные контрольные разряды |
| Паспорт РФ | `PASSPORT` | Шаблон серии и номера + проверка кода региона ОКАТО | Первые 4 цифры (серия: регион и год выдачи) и все разделители |
| Банковская карта | `BANK_CARD` | Шаблон 13–19 цифр + алгоритм Луна | Первые 6 цифр (BIN), последние 4 цифры, разделители и контрольная сумма Луна |
| Номер ОГРНИП | `OGRNIP` | Шаблон 15 цифр + остаток от деления на 13 | Первые 5 цифр (признак `3`, год регистрации, субъект РФ) и контрольный 15-й разряд |
| IP-адрес | `IP` | Парсер протоколов `IPv4` / `IPv6` | Семейство протокола и принадлежность к частной (`10/8`, `172.16/12`, `192.168/16`) или публичной подсети |
| Электронная почта | `EMAIL` | Шаблон RFC 5322 | Домен после `@`, длина, регистр и пунктуация локальной части |
| Свидетельство о рождении | `BIRTH_CERT` | Римская серия + 2 буквы кириллицы + 6 цифр | Серия документа (например, `III-МЮ`) и разделители |
| Код КЛАДР | `KLADR` | Шаблон 13 и 17 цифр + код региона и актуальности | Код субъекта РФ (первые 2 цифры), признак актуальности (`00`) и иерархия блоков |

Дополнительно поддерживаются атрибуты `PATRONYMIC` (Отчество), `PHONE` (Номер телефона) и `SNILS` (СНИЛС).

## 2. Структура проекта

| Файл / Каталог | Назначение |
|---|---|
| `recognizer.py` | Гибридный модуль распознавания ПДн (`extract_pii`) и функции валидации контрольных разрядов |
| `anon.py` | Модуль синонимического обезличивания (`anon`, `mask_pii`), морфологического анализа и снятия омонимии |
| `cli.py` | Интерфейс командной строки для распознавания и обезличивания произвольного текста |
| `demo.py` | Демонстрация работы всех алгоритмов, идемпотентности и снятия морфологической омонимии |
| `generate_dataset.py` | Генерация и разметка тестового корпуса Варианта 24 (`data/test_variant24.jsonl`, 150 текстов) |
| `evaluate_recognition.py` | Оценка качества распознавания ПДн (Token Classification BIO: `Precision`, `Recall`, `F1`, `Macro-F1`, `Weighted-F1`) |
| `evaluate_bertscore.py` | Оценка сохранения семантического содержания методом `BERTScore` (сравнение с маскированием `*`) |
| `train_model.py` | Скрипт подготовки корпуса `factRuEval2016` и дообучения модели `DeepPavlov/rubert-base-cased` |
| `test_project.py` | Набор из 64 модульных автотестов (`unittest`) |
| `data/` | Размеченные датасеты (`.jsonl`) и результаты экспериментальной оценки (`.json`) |
| `model/rubert_pii_ner/` | Дообученная нейросетевая модель `RuBERT` (автоматически собирается из частей `model.safetensors.part*` при первом запуске) |
| `Otchet_KR_Skotnikov.docx` | Отчёт по курсовой работе |

## 3. Установка и запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Использование из командной строки (`cli.py`)

```powershell
# Распознавание и синонимическое обезличивание текста
python cli.py "Андрей Яковлев отправился на прогулку" -v

# Несколько вариантов обезличивания
python cli.py "Алексей Долматов передал договор Алексею Долматову" --repeat 3

# Вывод результата и найденных сущностей в JSON
python cli.py "Иван получил кредит" --json
```

### Использование из Python API (`anon.py`)

```python
from anon import anon

# Режим полного конвейера: возвращает (обезличенный_текст, список_атрибутов)
new_text, entities = anon("Иван получил кредит")
# например: ("Пётр получил кредит", [["NAME", 0, 4]])

# Обезличивание заранее известных спанов: возвращает str
anon("Иван получил кредит", [["NAME", 0, 4]])
```

### Демонстрация, тесты и расчёт метрик

```powershell
# Демонстрация всех возможностей и сквозного конвейера
python demo.py --full

# Запуск 64 модульных тестов
python -m unittest -v test_project

# Перегенерация тестовой выборки (150 текстов, >= 100-150 экземпляров каждого атрибута)
python generate_dataset.py

# Оценка качества распознавания ПДн (Token Classification BIO)
python evaluate_recognition.py

# Оценка сохранения смысла через BERTScore (Синонимия vs Маскирование '*')
python evaluate_bertscore.py
```

## 4. Сводка экспериментальных результатов

- **Качество распознавания ПДн (`evaluate_recognition.py`, 150 документов — 90 на базе реальных предложений `factRuEval2016` + 60 деловых текстов с граничными форматами и «ловушками», 6093 токена):**
  - Средняя мера по классам ПДн: **$\text{Macro-F1} = 0{,}9530$** (требование $\ge 0{,}80$);
  - Средневзвешенная мера по ПДн: **$\text{Weighted-F1} = 0{,}9590$** (с учётом класса `O` — **$0{,}9790$**, требование $\ge 0{,}85$).
- **Сохранение семантического содержания (`evaluate_bertscore.py`, официальная библиотека `bert-score`, модель `DeepPavlov/rubert-base-cased`, 150 документов):**
  - Оригинал vs Синонимическое обезличивание: **$F1_{\text{BERT}} = 0{,}9286$** ($P = 0{,}9239$, $R = 0{,}9335$);
  - Оригинал vs Маскирование атрибутов ПДн (`*`): **$F1_{\text{BERT}} = 0{,}5761$**;
  - Оригинал vs Полное маскирование текста (`*`): **$F1_{\text{BERT}} = 0{,}3258$**;
  - Прирост $F1_{\text{BERT}}$ синонимического метода над маскированием ПДн: **$+0{,}3525$** ($+35{,}25$ п.п.).
